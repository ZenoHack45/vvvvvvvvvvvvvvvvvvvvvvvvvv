Frequently Asked Questions

How do I install the runtime?

Download the .zip file and extract it to a folder. Go to chrome://extensions, enable "Developer Mode" at the top right, and click "Load Unpacked." Select the extracted folder to initiate the sync.

Why does it need these permissions?

To reduce API latency between Roblox and Discord, the extension requires access to webRequest headers. This ensures that webhook pings are delivered in < 10ms.

Does this fix "Forbidden" errors?

Yes. By running at the browser level, the System Core bypasses standard Content Security Policy (CSP) blocks that cause script execution failures in the developer console.
